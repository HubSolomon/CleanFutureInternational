# Clean Future International — CFI 2.0

Strategic architecture, operating model and supporting materials for **Clean Future International (CFI)**,
a mission-driven international development and impact-infrastructure organization registered in the United
Kingdom and operating initially in Ghana.

> CFI does not only build infrastructure. CFI builds infrastructure that is designed, financed, operated,
> maintained and measured throughout its useful life.

## The model in brief

CFI's project lifecycle runs across twelve stages, each closed by an approval gate:

```
DISCOVER → VERIFY → DESIGN → FUND → BUILD → COMMISSION
    → OPERATE → MAINTAIN → MEASURE → LEARN → REINVEST → SCALE
```

Construction is one stage in that chain, not the end of the work. A project is complete when a named
operator, a funded maintenance plan and a measurement routine are all in place and working.

### The seven strategic pillars

1. Community & Need
2. Engineering & Innovation
3. Infrastructure Delivery
4. Sustainable Finance
5. Operations & Asset Management
6. Impact, Data & Learning
7. Institutional Strength & African Scale
